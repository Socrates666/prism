【执行纪律 · 最重要】
1. 第一个动作必须是 python 工具(开始写阶段1代码), 不要先说计划。
2. 分阶段做(见下), 每阶段一轮或几轮, 每轮都必须以 python 工具调用结束。做完一阶段立即进入下一阶段, 不停下等我。
3. 自检也是 python 工具(读文件 / node 跑纯函数), 不是文字描述。
4. 只有全部阶段完成、6 个纯函数验证通过, 才用文字报告完成。禁止"我将…/接下来我会…"作为一轮结尾。

【游戏 · 幽域深渊】回合制 roguelike 地牢爬行。
- 地图: 网格瓦片(墙/地/门/楼梯), 程序生成, 多房间 + 走廊连通, 越深越大。
- 玩家: 方向键移动, 攻击相邻敌人, 捡物品。属性 HP/MP/攻击/防御/楼层。
- 视野: fog of war, 只显示当前视野(半径) + 已探索区(暗化)。
- 战斗: 回合制。玩家行动后敌人行动。敌人显示"意图"(下回合将攻击X / 防御 / 技能)。伤害 = max(1, 攻击 - 防御)。
- 敌人 ≥3 种: 近战追击(BFS 扑向玩家) / 远程射击(直线射程) / 巡逻(固定路线)。
- 物品: 药水(回血/回蓝/增益)、武器(加攻击)、护甲(加防御)。背包。
- 楼层: 踩楼梯下一层, 敌人变强。死亡 = 永久结束(roguelike)。最高楼层存 localStorage。
- UI: 画布(地图 + 实体) + 侧栏(HP/MP/攻防/楼层/最高/背包) + 消息日志(最近 5 条战斗事件)。暗色主题。

【分阶段(每阶段做完自检再进下一阶段)】
阶段1·地图生成: 网格 + 房间 + 走廊, 保证全连通(无孤岛房间)。暴露 window.testMapGen(seed) 和 window.testConnectivity(grid)。自检: 任意种子生成的地图全连通。
阶段2·移动 + 视野: 玩家移动(撞墙不动), fog of war。暴露 window.testFOV(grid,x,y,r)。自检: 视野内格子正确显示, 墙后不可见。
阶段3·战斗: 回合制, 敌人意图, 伤害 = max(1, atk - def)。暴露 window.testCombat(atk,def,buffs)。自检: 伤害公式对、意图显示对。
阶段4·敌人 AI: 近战追击 / 远程 / 巡逻, BFS 寻路。暴露 window.testEnemyAI(enemy,player,grid) 和 window.testPathfind(grid,from,to)。自检: 近战敌人能绕墙追到玩家。
阶段5·物品 + 楼层: 药水 / 武器 / 护甲, 楼梯下楼, 永久死亡, localStorage 存最高层。自检: 完整可玩一局(出生→战斗→捡物→下楼→死亡→重开)。
阶段6·总自检 + 平衡: 实玩 2-3 层, 6 个纯函数全验, 调数值平衡。完成后调一次 reflect 总结关键决策。

【完成后判据】6 个纯函数全对 + 实玩 2-3 层无崩溃 + 战斗/视野/AI/物品/楼层都生效。全部通过后用文字报告完成并给绝对路径。
