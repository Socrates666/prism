【★ 子 agent 协作 · 必做(本次测试重点)】
你有一个 spawn 能力。这次必须真用一个子 agent 分工, 验证链路:
1. 用 python 工具 spawn 一个子 agent(名叫 wave-designer):
   ```
   from prism.spawn import spawn
   wd = spawn("wave-designer", Prism.model, parent=Prism)
   ```
2. 给它派活(inject), 让它独立写"敌人波次生成 + 敌人类型"模块(纯函数, 存到它的 workspace):
   ```
   wd.inject({"type": "run", "input": "你是 wave-designer 子 agent。用 write 工具把敌人波次模块写到 waves.js：导出 window.testWave(n) 返回第 n 波的敌人序列(数组, 每元素 {type, hp, speed, x})；至少 3 种敌人(scout 快低血/cruiser 中中/battleship 慢高血), 每 5 波出一个 boss。波次表用纯函数算。写完告诉我文件路径。"})
   ```
3. 轮询等它做完, 读它的产出:
   ```
   import time
   while not wd.last_result: time.sleep(2)   # 或读 wd.messages
   print(wd.last_result)
   # 读它写的文件
   open("workspaces/wave-designer/waves.js", encoding="utf-8").read()
   ```
4. 把 waves.js 内容内联进 game/index.html, 集成到主游戏循环。
TUI 里应能看到 [wave-designer] 子 agent 的输出(行动/观察带标签) —— 这就是子 agent 协作的白盒证据。如果 spawn/inject/读结果任一步失败, 用 python 调试并报告。

【游戏 · Stellar Drift】
- 玩家: 方向键/AD 移动, 空格射击。HP/分数/波次。
- 敌人: 从顶部下来, 多种(scout/cruiser/battleship + 每5波 boss), 波次用子 agent 写的 waves.js。
- 战斗: 子弹击中敌人扣血, 敌人撞玩家或到底扣 HP。爆炸效果(精灵或粒子)。
- 道具: 偶尔掉落(回血/双发/护盾)。
- 音效: 射击/爆炸/受伤(从素材库下或 WebAudio 合成)。
- 进度: 无限波次越来越难, 最高分存 localStorage。死亡重开。
- UI: 画布 + 侧栏(HP/分数/波次/最高分)。暗色太空主题, 星空背景滚动。
