【游戏 · 逃离鸭科夫(俯视 twin-stick 搜刮射击)】
- 玩家: 鸭子。WASD 移动, 鼠标瞄准, 左键射击。HP/部位/背包。
- 地图: 用 map-designer 的 testMapGen 生成城市废墟(墙/掩体/巷道), 散落物品点(箱子/鸭尸), 1-2 个蓝色撤离点。
- 射击: 子弹飞行+碰撞。武器 ≥3(呱呱手枪/霰弹面包圈/步枪), 各有散布/伤害/射速。
- 搜刮: 走近物品点按 E 开搜刮界面, 选物品拿取(受库存限制, 用 inventory-designer 的 testInventoryAdd)。
- 库存: 4×4 网格(用子 agent 的), 武器2格/医疗1格/杂物1格。满了拿不动。
- 受伤(硬核): 6 部位(头/胸/腹/左臂/右臂/双腿)各 HP。腿伤→移速降, 臂伤→射击散布大, 头/胸清零→死。暴露 window.testDamage(part, dmg)。
- 医疗: 绷带(止血)/夹板(治腿)/急救包(全治), 对应部位。
- 敌人: Scav 灰鸭, AI 巡逻→视野发现→追击→射击, 不同武器。暴露 window.testEnemyAI(enemy, player, grid)。
- 撤离: 走到撤离点按住 F 倒计时 10s, 撤出带物品进仓库; 被打断(受伤/离开)重置。
- 仓库: 撤出物品存 localStorage, 下局可带装备入场。
- 恶搞: 呱呱音效(射击/受伤/搜刮)、面包圈(货币)、鸭蛋(高价物品)、Boss 波格丹大鸭(重装备)。
- UI: 画布(俯视地图+鸭) + 侧栏(部位HP/背包网格/武器/货币) + 搜刮弹窗。暗色废墟风。

【可测性 · 暴露 5 个纯函数】
  window.testMapGen = (seed) => {grid, extractPoints, lootSpots}   // 子 agent
  window.testInventoryAdd = (grid, item) => 加后库存                // 子 agent
  window.testLoot = (container) => 物品数组                          // 子 agent
  window.testDamage = (part, dmg) => 部位状态+debuff                // 主 agent
  window.testEnemyAI = (enemy, player, grid) => 行动决策             // 主 agent
