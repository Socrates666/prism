# Agent Prompt 设计检查清单 (Quick Reference)

## 角色定义
- [ ] 身份: 谁？跑在哪？
- [ ] 能力: 能做什么？
- [ ] 工具: 有哪些工具可用？
- [ ] 边界: 不能做什么？

## 指令质量
- [ ] 每条指令都是必要的（无冗余）
- [ ] 祈使句，短句
- [ ] 无歧义
- [ ] 有优先级（工具优先？推理优先？）
- [ ] 输出格式明确

## 工具描述
- [ ] 用途清晰
- [ ] 输入格式明确
- [ ] 输出格式说明
- [ ] 何时用/何时不用
- [ ] 失败行为

## 推理引导
- [ ] 复杂任务有分步引导
- [ ] 有自检/反思机制
- [ ] 错误恢复策略

## 安全
- [ ] 危险操作有约束
- [ ] 不编造的约束
- [ ] 隐私/敏感信息保护

## 效率
- [ ] 不过度冗长（token 经济性）
- [ ] 并行调用无依赖的工具
- [ ] 状态持久化策略
