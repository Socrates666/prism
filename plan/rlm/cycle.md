# ★ 认知周期:READ / WRITE / 剪枝

> werden round 5–7 的结论。本篇回答:**直觉和改树怎么分工、三难怎么解、剪枝何时触发。**

## 一句话

**直觉 = READ(选/排/临时压),每次 loop 跑,焊进不可变 core,不可绕过。改树 = WRITE(剪枝),结构阈值触发,非 agent 判断、非每次 loop。** 这把"不可绕过 + 不每次 loop + 不是工具"的三难拆开。

## 认知周期

```
┌─────────────────────────────────────────────────────────┐
│  1. 直觉(scribe):  读树 → 选/排/压 → search-state     │ READ
│     上下文。焊进 core, 不可绕过。                        │
│  2. 思考(主模型):  context → 下一 thought / 决策回溯   │ (写节点/标failed)
│  3. 行动:          执行工具 / spawn                      │
│  4. 观察:          result → 更新树                       │ WRITE
└─────────────────────────────────────────────────────────┘
                          ↓ 回 1
```

备选框架(同循环的科学化重命名):**假设 → 实验 → 反思**。

## 三难怎么解(round 6–7)

werden round 6 用户撞进的三难:**不可绕过 + 不每次 loop + 不是工具 —— 三选二,第三个必死。**

解法:用户把"直觉"和"改树"焊死了。拆开:

| | 做什么 | 每次 loop? | 膨胀? |
|---|---|:---:|:---:|
| **直觉 = READ** | scribe 读树、拼 search-state | 是 | **不**(一个字不写) |
| **改树 = WRITE** | 往树加节点 / 标 failed / 剪枝 | 否 | 是 |

直觉是 READ → 每次 loop 跑不膨胀 → **不可绕过 + 每次 loop** 成立(焊进 core)。
改树是 WRITE → occasional → **不每次 loop + 不是工具**(结构触发)成立。

每个动作满足三难中的两个,合起来全满足。三难塌。

## 直觉的 assembly:选 / 排 / 压

直觉(小模型)把树变 search-state prompt,干三件事:

1. **选** —— 这一刻哪些节点相关?(recency?当前任务的因果祖先?references?)
2. **排** —— 什么顺序?(时间?因果链?重要度?)
3. **压** —— 每个节点放多少?(全文?折叠?)

> "直觉" = 小模型做选+排+压,模拟"现在什么要紧"的 gut feel。**拼的是 search-state**(根→frontier 决策路径 + 失败兄弟支 + 当前上下文),不是从仓库选 context。

## 压 = READ vs WRITE(master switch)

round 7 的关键:**压是临时缩写(READ),还是把摘要存回树当新节点(WRITE)?**

| | 行为 | 后果 |
|---|---|---|
| **压 = READ** | 只在 context 里临时缩写,不写回 | 不膨胀,直觉每次 loop 安全,**三难当场塌** |
| **压 = WRITE** | 摘要存回树 | 每次 loop 写 → 膨胀恐惧复活 |

**结论:压 = READ(临时缩写)。** 不写回 → 不膨胀。

### 反向压力 → 逼出剪枝(第三触发器)

压=READ 有隐性代价:**每次 loop 小模型得重新读整棵(未压缩)树再缩写**。树小没事;树一大,**小模型输入先爆**(哪怕输出 context 是 bounded)。

撑不住那一刻,**被迫 WRITE = 剪枝**:把老子树压成摘要节点存回,控规模。而这个"被迫"的触发——

**它不是 agent 判断(≠工具)、不是每次 loop(只在超阈值时)。是结构阈值**(树超 N 节点 / 任务边界)。**这恰好是 round 6 满世界找的"第三触发器"** —— 它一直藏在 assembly 的压-设计里。

## READ/WRITE/剪枝 分工

| 机制 | 类型 | 触发 | 位置 |
|------|:----:|------|:----:|
| 直觉(选/排/临时压) | READ | 每次 loop | core,不可绕过 |
| 加节点(新 thought/action/result) | WRITE | 每个 loop 自然产生(搜索生长) | core loop |
| 标 failed + 回溯 | WRITE | 主模型/小模型判定(见 α/β open) | core loop |
| **剪枝**(老子树压成摘要存回) | WRITE | **结构阈值**(超 N 节点 / 任务边界) | core,结构性 |

> 搜索树本就该随搜索生长(不是病),增长由**搜索纪律**兜底:剪枝 + 深度上限 + 小模型启发式不探烂支。
