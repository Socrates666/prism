## 怎么读

每份日志包含：

- **当日概览** — 做了什么、推进到哪
- **时间线** — 按 commit 顺序（含时间戳、哈希、说明）
- **分阶段叙事** — 设计决策、实现、踩坑、修复
- **关键技术决策** — 为什么这么做
- **当前状态 / 下一步**

源代码现状以仓库 `prism/` 目录为准，日志只记录"为什么演化成现在这样"。
