## 阶段 N · 结构化 system prompt（阶段 13）★本次重点

**设计动机**：之前 `system_prompt` 是一整段字符串（角色/环境/能力/指令/准则混在一起）。拆成**结构化段**，各段独立可组合/覆盖，`/goal` `/skill` 注入对应段（不再混入 extra）。

**`prism/prompt.py` SystemPrompt 类**——8 段：

| 段 | 内容 | 来源 |
|----|------|------|
| role 角色 | 你是 {name}（main 完整IPython / sub 工厂受限） | 默认(按 kind) |
| environment 环境 | textual TUI / IPython 内核 / workspace | 默认 |
| capabilities 能力与工具 | python 工具(主) / 文件工具(子) | 默认(按 kind) |
| instructions 指令 | 输入即授权 / @ 路由 / 直接敲 Python | 默认 |
| guidelines 行为准则 | 简洁直接 / 不确定就说不确定 / 不编造 | 默认 |
| goal 目标 | 当前 goal | `/goal` |
| skills 技能 | skill 列表 | `/skill` |
| extra 自由追加 | 兼容旧 append | 运行时 |

**接口**：`render()`（markdown `## 段标题` 组合）/ `set_override`（整体替换，对齐 pi）/ `set_goal` / `add_skill` / `add_extra`。

**Agent 接入**：`self.prompt = SystemPrompt()`；`system_prompt` 改 **property → `prompt.render()`**（动态）；`_fill_default_prompt` 按 kind 填默认段；`append_to_system_prompt`→`add_extra`；override/append 兼容。`/goal`→`set_goal`、`/skill`→`add_skill`（结构化段，非 extra）。

**渲染效果**（默认 main agent）：
```
## 角色
你是 main, prism 里的 agent(主 agent, 享完整 IPython)。
## 环境
prism 是 textual 全屏 TUI... 你跑在 IPython 内核里...
## 能力与工具
你有 python 工具: 在共享命名空间执行 Python...
## 指令
用户通过 @ 消息跟你对话... 输入即授权...
## 行为准则
简洁、直接、准确。不确定就说不确定...
```
`test_prompt` 7 个 + 全套 **98 passed**。
